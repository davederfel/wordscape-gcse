# Backgrounds

The landscape pictures shown behind the game. You can replace any of them, add more, or give a topic its own set.

## Where they go

| Folder | Used for |
|---|---|
| `assets/backgrounds/` | The default set, used by every topic that does not have its own. |
| `subjects/<subject>/<topic>/backgrounds/` | A topic's own set. If this folder has any images, the topic uses only these. |
| `subjects/english/backgrounds/` | The english subject's own set. |

The game moves to the next picture at each new level, in alphabetical order of file name, and starts again after the last one. To control the order, start the file names with numbers, for example `01-lake.jpg`, `02-hills.jpg`.

## Swapping in your own

1. Put the image in the folder you want, or delete one you don't want. The default folder must keep at least one image.
2. Run `python tools/build_backgrounds.py`. A web page cannot look inside folders by itself, so this writes the list of images the game reads (`backgrounds.json`). Run it whenever you add, remove or rename an image.

## What makes a good background

- **Portrait,** the shape of a phone screen. 1080 x 1920 pixels is ideal; anything in a similar 9:16 shape works. Other shapes are cropped to fit.
- **JPG, PNG or WebP,** ideally under 500 KB so the game loads quickly.
- **A long-distance view,** soft and calm, without strong detail. The letter tiles and the letter wheel sit on top of it and must stay easy to read.
- **A quiet lower half.** The letter wheel covers most of the bottom of the screen.
- **No birds.** The game animates its own flock across the sky.
- **Pictures you have the right to use:** your own photos, or ones with a licence that allows reuse (for example, Unsplash or Pexels). This matters because the repository is public.

## The default set

The eight pictures supplied are original paintings generated by `tools/paint_backgrounds.py`, so there is no licence to track. To regenerate them exactly, or to change a scene's colours, edit the `SCENES` list in that file and run `python tools/paint_backgrounds.py`.

| File | Scene |
|---|---|
| `blue-morning.jpg` | Blue morning sky, mountains and a lake |
| `dawn-mist.jpg` | Pink dawn, misty mountains |
| `golden-hills.jpg` | Pale gold sky, rolling hills |
| `green-valley.jpg` | Light blue sky, green rolling hills |
